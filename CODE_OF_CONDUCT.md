# Code of conduct

Roadbeat follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone who takes part in the project's issues, pull requests and discussions is expected to follow it.

## Reporting

To report behaviour that breaks the code of conduct, contact the maintainer privately, either through GitHub's private reporting on [the repository](https://github.com/realbakari/Roadbeat) or through the [contact page](https://www.roadbeat.app/contact/). Reports are kept confidential, and every report is reviewed.

The maintainer applies the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): correction, warning, temporary ban or permanent ban, depending on what happened.
