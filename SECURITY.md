# Security

## Report a vulnerability

Please report security problems privately. On the [Roadbeat repository](https://github.com/realbakari/Roadbeat), open the **Security** tab and choose **Report a vulnerability**. This uses GitHub's private vulnerability reporting, so only the maintainer sees your report.

Never report a vulnerability in a public issue, pull request or discussion.

Say what you found, how to reproduce it, and what someone could do with it.

## What's in scope

- The site at https://www.roadbeat.app and the code in this repository.
- The API at `/api/*`.
- The MCP server at `/mcp`.
- The stores behind push alerts and feedback (Upstash Redis): commute subscriptions, feedback messages and the visitor counts.

Problems in the official feeds Roadbeat reads belong to their publishers. See the [Contact](https://www.roadbeat.app/contact/) page for where to report those.

## No bounty

Roadbeat is a free project. There is no bug bounty.
